# комп website

The landing page for [комп](https://github.com/samchinmaya/komp), live at
https://samchinmaya.github.io/komp. Next.js 16 (static export) + Tailwind CSS 4.

```bash
npm install
npm run dev          # http://localhost:3000
```

Production build, as GitHub Pages runs it (the site lives under `/komp`):

```bash
PAGES_BASE_PATH=/komp npm run build   # writes out/
```

- `src/app/page.tsx`: the page
- `src/components/`: wordmark (with the black-hole о), blueprint grid, grainy glow, demo viewer
- `src/data/demos.json`: real комп output, regenerated by `scripts/build_site_demo.py`
- `public/blackhole-*.png`, `public/dither-band-signal.png`: from `scripts/gen_blackhole.py` and `scripts/gen_dither.py`
