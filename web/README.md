# комп website

The landing page for [комп](https://github.com/samchinmaya/komp), live at
https://samchinmaya.github.io/komp. Next.js 16 (static export) + Tailwind CSS 4.

```bash
npm install
npm run dev          # http://localhost:3000
```

Production build, as GitHub Pages runs it (the site lives under `/komp`):

```bash
PAGES_BASE_PATH=/komp npm run build   # writes out/
```

- `src/app/page.tsx`: the page, "The комп manual" (paper/ink, Instrument Serif)
- `src/components/manual/`: animated black-hole wordmark, Fig. 1 isometric machine,
  Fig. 2 lane diagram, grainy-gradient and dithered-gradient plates
- `src/components/DemoViewer.tsx`, `LogOutput.tsx`: the before/after specimens
- `src/data/demos.json`: real комп output, regenerated by `scripts/build_site_demo.py`
- `public/dither-plate.png`: from `scripts/gen_dither.py`
